# endgame_standings

Plays **once, no loop**, on the host screen at the final standings — the podium
at the end of a match.

**Empty is a real setting**, the same as `midgame_standings/`: with no file in
here the `round_results/` track keeps playing from the last reveal into the
podium rather than cutting to silence.

Drop one `.mp3` or `.ogg` in here. The filename does not matter.
